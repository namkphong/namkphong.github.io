DMX · REALTIME

Báo cáo realtime tự động

Tự lấy file từ dashboard 77 → tạo ảnh → đẩy lên kho. Nhân viên gõ /số trong LINE là có ảnh mới nhất. Chạy được ngay trên điện thoại.

01

Cài trình quản lý userscript

Chrome trên Android không cài được tiện ích. Dùng Firefox (bản thường) rồi thêm Violentmonkey: menu ⋮ → Tiện ích → tìm Violentmonkey → Thêm.

Mở trang Violentmonkey
02

Cài 2 script

Bấm từng nút. Violentmonkey hiện trang xác nhận → chọn Cài đặt (Install). Cài xong bấm nút thứ hai.

Cài / Cập nhật A · Đẩy ảnh & dòng hàng Cài / Cập nhật B · Tự động (dashboard→ảnh→đẩy)

A tạo nút “Đẩy ảnh” trên realtimenv.html. B tự tải file từ ManagerDownload rồi nhờ A đẩy. Phải cài cả hai.

Cần cài thêm script Lấy số hằng ngày trước — nó tạo cấu hình cụm mà 2 script này dùng. Xem trang cài đầy đủ.

03

Đăng nhập một lần

Firefox là trình duyệt riêng nên phải đăng nhập lại dashboard 77. Làm một lần, sau nhớ luôn.

Đăng nhập dashboard 77 MWG

Không phải nhập mã cụm hay token gì — script tự nhận ra cụm của bạn từ chính trang MWG.

04

Chạy

Không phải bấm từng bước nữa — script tự làm cả chu kỳ: xuất excel cho mọi siêu thị trong cụm → tải về → dựng ảnh → đẩy lên.

  1. Mở dashboard 77. Panel DMX Auto hiện dưới màn hình.
  2. Bật ⏰ Tự chạy mỗi 10 phút. Giữ nguyên tab đó, đừng đóng.
  3. Script tự chạy lại mỗi 10 phút trong khung 8–22h. Nhóm LINE gõ /số là có ảnh mới nhất.
  4. Muốn chạy ngay một lần thì bấm ▶ Chạy tất cả trong panel.

Nếu MWG đăng xuất giữa chừng, script dừng lại và gửi cảnh báo Telegram (nếu bạn đã cấu hình) — đăng nhập lại là nó chạy tiếp.

Khi có lỗi

Mọi bước đều in ra khung đen trong panel. Chụp khung đó là đủ để tìm nguyên nhân.

Không thấy “Tải file excel”Bảng chưa cập nhật. Bấm Làm mới bảng trong panel.
Chưa “Đã xuất xong”File còn đang xuất. Đợi thêm rồi bấm lại.
Không thấy nút Đẩy ảnhChưa cài script A, hoặc chưa tải lại trang. Tải lại realtimenv.html.
Trang chưa phân tích fileFile tải về lỗi/rỗng. Xuất lại rồi thử lại.
Chưa có cấu hình siêu thịChạy LẤY TẤT CẢ DATA trên BI một lần trước — cấu hình cụm sinh ra từ đó.
Không gắn được siêu thị cho dòng hàng nàoCụm chưa có mã MWG. Mở Báo cáo giờ công → panel GC → Tự dò mã MWG.
Các file script công khai nhưng không chứa token — token LINE/Telegram lưu riêng (trong máy / Apps Script). Cập nhật: Violentmonkey tự tải bản mới; muốn ngay thì bấm lại nút Cài / Cập nhật ở trên.
